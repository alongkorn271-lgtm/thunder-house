# thunder-house — บ้านจากโมเดลก่อสร้างทีละขั้น ถึงงานส่งมอบ

โมเดลก่อสร้างคือแหล่งความจริงเดียว: ปริมาณ ผัง รูปตัด หน้าเว็บ ตัวเลขต่อรอง และภาพ ถอดจากรูปทรงในโมเดล
ไม่วาดเส้นเอง ไม่พิมพ์ตัวเลขเองถ้าอ่านจาก report ได้ — แก้โมเดลแล้ว build ใหม่ ทุกอย่างสร้างใหม่ได้ด้วยสคริปต์ชุดเดิม
skill นี้ใช้งานจบในตัว (ไม่ต้องมี skill อื่น) · ตอบเป็นภาษาไทย ชื่อไฟล์/ออบเจกต์เป็นภาษาอังกฤษ

## สคริปต์
คัดลอกไปไว้ในโปรเจกต์ก่อนแก้ (อย่าแก้ในโฟลเดอร์ skill) — ทุกไฟล์ใช้งานจริงกับบ้านตัวอย่าง KK01 · จุดที่ต้องแก้ต่อโปรเจกต์: `references/project_config.md`

| โฟลเดอร์ | ไฟล์ |
|---|---|
| `scripts/model/` | โมเดลก่อสร้าง ST00–ST20: `kk01_load.py`, `th_base.py`, `th_steel.py`, `kk01_*.py`, `build_kk01.py`, `test_st*.py`, `kk01_furniture.py`, `q_rooms.py` |
| `scripts/blender/` | `export_model_json.py` (รูปทรง → JSON) · `render_sheets.py` (ภาพนำเสนอทีละขั้น) · `render_sales.py` + `export_sales_json.py` (โมเดลขาย) · `th_views.py` (กล้องระดับ + Material ID map) |
| `scripts/viewer/` | `template.html` + `build_site.py` (หน้าเว็บ 3D) · `make_offline.py` (HTML ไฟล์เดียว ฉบับเต็ม + ฉบับส่งต่อ) |
| `scripts/boq/` | `boq_parse.py` (อ่าน PDF ผรม. + ตรวจเลข) · `make_xlsx.py` + `recalc_excel.ps1` (Excel 5 แผ่น) |
| `scripts/drawings/` | `make_sheets.py` + `sheets_late.py` + `lib/dwg_lib.py` + ฟอนต์ไทย · `render_pdf.py` (Chrome → PDF A3 บีบอัด) |
| `scripts/furnishing/` | `check_refs.py` (เช็กรูปอ้างอิงครบ) · `make_flow_pack.py` (ชุดไฟล์ Google Flow) |

## ลำดับงาน (ทำตามที่ผู้ใช้ขอ)

### 1. โมเดลก่อสร้างทีละขั้น — อ่าน `references/model_stages.md`
อ่านแบบทั้งชุด จดกริด ระดับ ขนาดหลักลง `FACTS.md` ก่อน · ปั้นทีละขั้น ST00 → ST18 แต่ละขั้นมี spec + ตัวตรวจ + mutation test
· build จาก Blender ว่างทุกครั้ง (`build_kk01.py`) · ต้อง `problems: 0` ทุกชุดทดสอบ

### 2. ส่งออกข้อมูล + ภาพ render
`OUT=data/model.json blender -b <Construction.blend> -P export_model_json.py` · `render_sheets.py` ทดสอบ 1 shot ก่อนแล้วค่อยรันทั้งชุดเบื้องหลัง
ลุค: isometric ortho, ขั้นปัจจุบันสีประจำขั้น ขั้นก่อนหน้าขาว, Freestyle — **ปิดเส้นขอบทุก shot ที่มีกระเบื้อง/สี/บ้านทั้งหลัง** (แรมพุ่ง 17 GB)
· ภาพเหล็กเสริม: คอนกรีตโปร่ง alpha ~0.07, เหล็กหนาขึ้น ×1.7

### 3. หน้าเว็บ 3D (artifact)
ถ้าผู้ใช้มี artifact ต้นแบบ อ่านด้วย Artifact `read` แล้วทำตามโครง · `build_site.py <build_report.log>` · แก้ array `BOQ`/`NEG`/`ISSUES`/`WASTE`
· ทดสอบ desktop + มือถือ 375 px + dark mode · publish พร้อม `files` ของภาพ (path ยาวเต็ม) · แชร์ออกนอกไม่ได้ → `make_offline.py`

### 4. เทียบ BOQ ผู้รับเหมา + ต่อรอง + Excel — อ่าน `references/boq_negotiation.md`
ฝั่งเรา = ปริมาณจริงจากโมเดล + เผื่อ · ฝั่ง ผรม. = ตามใบทุกบรรทัด · มูลค่า = ส่วนต่าง × ราคาต่อหน่วยของ ผรม. (ของ + แรง)
· 4 กลุ่ม: ต้องได้ตามแบบ / รายการที่ขาด / เผื่อเกิน / ของที่ขอเพิ่ม · แท็บต่อรองเป็นของภายใน ห้ามส่ง ผรม.

### 5. ชุดแบบ A3 — อ่าน `references/drawing_sheets.md`
1 แผ่นต่อ 1 ขั้น: กล่องข้อมูล + ผัง 1:125 + ตารางปริมาณ (ซ้าย) · ภาพ render + ภาพรายละเอียด + รูปตัด/รูปด้าน (ขวา)
· หาระนาบตัดจากโมเดล (อย่าเดา) · เปิดดู PNG ทุกแผ่นแก้ซ้อน 2–3 รอบ · DRAFT ช่องลงนามว่าง

### 6. เฟอร์นิเจอร์ โมเดลขาย ภาพ AI — อ่าน `references/furnishing.md`
โฟลเดอร์รูปอ้างอิง + ตัวเช็ก → prompt สไตล์จากรูป → ST20 ทรงก้อนขนาดจริง (ทั้งโมเดลก่อสร้างและโมเดลขาย) →
กล้อง + ID map → ชุดไฟล์ Google Flow → ตรวจภาพ AI ว่าเป็นบ้านหลังเดิม → ใส่หน้าเว็บ

### 7. ส่งงาน
บอก: รายการ, ข้อสมมติ, สิ่งที่ยังไม่ได้ตรวจ, ขนาดไฟล์, สิ่งที่ยังไม่ commit · commit เฉพาะเมื่อผู้ใช้สั่ง ·
ไม่ commit ภาพ render / PNG ตรวจแบบ / รูปอ้างอิง (`.gitignore`) · สำรอง .blend ก่อนแก้ทุกครั้ง

## บทเรียนจากงานจริง
- เขียน patch ที่มี `\n` quote ซ้อน หรือ backslash ด้วย Write tool เป็นไฟล์ .py แล้วรัน — heredoc พังบ่อย
- Windows: `PYTHONIOENCODING=utf-8` ก่อนพิมพ์ไทย · Artifact `files` ใช้ path ยาว ไม่ใช่ `ALONGK~1`
- อย่า `taskkill /IM blender.exe` แบบเหมา (ปิด Blender ของผู้ใช้ด้วย) — ใช้ TaskStop
- หน้าเว็บหนักโหลด ~6 วินาที: ภาพหน้าจอตอนกำลังโหลดเป็นสีดำ ไม่ใช่ error — เช็ก `meshes.length` ก่อนสรุป
- ข้อมูลที่จะเผยแพร่ (GitHub, ลิงก์สาธารณะ): แทนราคา/ตัวเลขต่อรองจริงด้วยค่าตัวอย่าง, เบลอส่วนที่มีข้อมูลในวิดีโอ, ไม่ใส่รูปที่ไม่มีสิทธิ์
- อ้างอิงงานคนอื่นเฉพาะที่มีสัญญาอนุญาตชัดเจน และระบุที่มา
- งานโครงสร้างทุกชิ้นเป็นแบบร่าง ต้องให้วิศวกรโยธาที่มีใบอนุญาตตรวจและลงนาม
