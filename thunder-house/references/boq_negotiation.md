# เทียบใบเสนอราคาผู้รับเหมากับโมเดล + จุดต่อรอง

## หลักที่ผู้ใช้กำหนด
- เทียบ **โมเดล (ปริมาณจริงของเรา) กับใบของ ผรม.** เท่านั้น — BOQ xlsx เก่าของเราไม่ใช่ตัวเทียบ (ค่าแรงยังไม่ปรับ, ปริมาณประมาณ)
- ฝั่ง ผรม. ยึดรายการ จำนวน หน่วย และราคาตามใบของเขาทุกบรรทัด เรียงตามหมวดของเขา
- ฝั่งโมเดลต้อง **เผื่อเศษ** ก่อนเทียบ (ผู้ใช้: "ปริมาณเราก็ควรทำเผื่อด้วยสิ") แสดง `สุทธิ → เผื่อแล้ว`
- ราคาที่ใช้คิดมูลค่า = ราคาต่อหน่วยของ ผรม. (ค่าของ + ค่าแรง ถ้าใบแยกไว้) — ถ้าผู้ใช้ทักว่าราคาสูงสุดแค่ X ให้ชี้บรรทัดใน PDF ว่ารวมค่าแรงแล้ว และบอกผลถ้าคิดค่าของอย่างเดียว

## อัตราเผื่อ (recommend ที่ใช้กับ KK01)
| หมวด | เผื่อ |
|---|---|
| คอนกรีต | 5 % |
| ทราย / คอนกรีตหยาบ | 10 % |
| เหล็กเสริม | +5 % บนจำนวนเส้นจากแผนตัด (ปัดขึ้น) |
| เหล็กรูปพรรณ / ระแนง | +5 % บนจำนวนเส้นจากแผนตัด (ปัดขึ้น) |
| ไม้แบบ, ทาสีกันสนิม, เมทัลชีท, เชิงชาย, รางน้ำ | 5 % |
| ผนัง ฉาบ สี เสาเอ็น เซี้ยม ฝ้า กระเบื้องพื้น/ผนัง | 5 % |
| กระเบื้องหลังคา / ครอบ | รวมในจำนวนแผ่นแล้ว (5 % / 3 %) |
| ท่อประปา / สุขาภิบาล | 10 % |
| แผ่นพื้น PS, ประตูหน้าต่าง, อุปกรณ์, สุขภัณฑ์ | 0 % (นับชุด/แผ่น) |

## กับดักหน่วย
- เหล็ก 2C (2[]) — ราคาต่อ "เส้น" ของ C125×50×20×2.3 มักเป็น **C เดี่ยวยาว 6 ม.** (≈27 กก.) — เช็กจากราคาต่อ กก. ดังนั้น 2C ยาว L ม. = L × 2 / 6 เส้น
- ค่าแรงติดตั้งเหล็ก / ค่าแรงมุง ผรม. คิดต่อ ตร.ม. ไม่ใช่ต่อเส้น → ส่วนต่างจำนวนเส้นคิดเฉพาะค่าของ (ระมัดระวังแล้ว)
- ไฟฟ้า ผรม. มักคิด "ต่อจุด" (สวิตช์/ปลั๊ก) รวมท่อ-สาย — ให้ถามยืนยันว่ารวมแล้ว อย่าเอาความยาวท่อไปเทียบตรง
- ผนังอิฐ: ผรม. มักไม่หักช่องเปิด — ระบุในหมายเหตุ ("ต่างแม้ไม่หักช่องเปิด")
- ใบเสนอราคาอาจเว้นจำนวน (ขุดดิน/ถมกลับ) — ถามว่ารวมในค่ารถแม็คโคหรือไม่ ไม่ใช่นับเป็นศูนย์

## 4 กลุ่มจุดต่อรอง (ลำดับในแท็บ "ต่อรอง")
1. **ต้องได้ตามแบบ — ไม่ใช่ของแถม**: วัสดุต่ำกว่าแบบ (เช่น LL แผ่นพื้น, ระยะ wire mesh, ขนาดเหล็กตะเข้/ดั้ง, ความยาวเสาเอ็น, เหล็กฐานราก)
2. **รายการที่ใบยังไม่มี** — จะกลายเป็นงานเพิ่ม (เช่น ท่อน้ำดี, บันได, กันซึม, สีฝ้า, มิเตอร์/หลักดิน)
3. **ปริมาณที่เผื่อเกิน** (หลังหักเผื่อของเราแล้ว) — ใช้เป็นคำถาม "คิดจากอะไร" ไม่ใช่ข้อกล่าวหา
4. **ของที่ขอเพิ่มแลกกับข้อ 3**: เลือกของที่ฝังในบ้าน ทำทีหลังยาก (เตรียมท่อแอร์, น้ำอุ่น, อัปเกรดกระเบื้อง); ตัวเครื่องแอร์ซื้อเองตอนโปรได้ → เก็บไว้ต่อรองท้ายสุด

สรุปบนสุด: ราคา ผรม. · เกิน · ต่ำกว่าแบบ · ผิดเลข · **ส่วนที่เหลือไว้ต่อรอง** 
มูลค่าตลาดที่ไม่มีในใบ (แอร์ น้ำอุ่น) ให้บอกว่าเป็นค่าประมาณ ต้องเช็กราคาจริง

## Excel (make_xlsx.py)
- อ่าน array `BOQ`, `WASTE`, `NEG` จาก template.html ของหน้าเว็บ (แหล่งเดียวกัน ตัวเลขตรงกัน)
- แผ่น "อัตราเผื่อ" เป็นช่องกรอก (ตัวสีน้ำเงิน พื้นเหลือง) → แผ่น "ต่อรอง" ใช้สูตร `=IF(ปัดขึ้น,ROUNDUP(net*(1+w),0),net*(1+w))`, `=ROUND((ผรม.−โมเดล)*ราคา,0)`
- สรุปด้วย `SUMIF(>0)` / `SUMIF(<0)` — จันทันเพิงที่ ผรม. ขาด จะไปอยู่ฝั่ง "ขาด" ทำให้ยอดแยกต่างจากหน้าเว็บเล็กน้อยแต่ยอดสุทธิเท่ากัน (บอกผู้ใช้)
- ฟอนต์ Tahoma (รองรับไทย) · คำนวณใหม่ด้วย Excel COM (`recalc_excel.ps1`) แล้วอ่านค่ากลับด้วย openpyxl `data_only=True`
- แผ่นที่ส่ง ผรม. ได้: "เทียบรายบรรทัด", "รายการขาด" — แผ่น "ต่อรอง"/"สรุป" เป็นของภายใน
