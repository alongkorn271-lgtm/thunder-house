## บทเรียนเรื่องตำแหน่ง
- ข้อความชี้ใส่คอลัมน์ขวาของรูปตัด และวางตาม **ระดับของจุดที่ชี้** (`calls()` เรียงตาม y แล้วกระจายห่าง ≥ 7 มม.) — ถ้าวางเป็นแถวที่ y คงที่ เส้นชี้จะทแยงผ่านรูปทั้งรูป
- ผัง 1:100 ใหญ่เกิน (ชนกล่องข้อมูลและคอลัมน์ขวา) → 1:125 แล้วตารางปริมาณไปอยู่ใต้ผัง
- เส้นบอกระยะห่างจากแนวกริดอย่างน้อย 8 มม. ไม่งั้นทับฐานรากริมนอก
- เปลี่ยนมาตราส่วนแล้วแก้ข้อความทุกจุด (ชื่อรูป, หัวกระดาษ, สารบัญ)
- view ที่ไม่ต้องการชื่อ อย่าใส่ `title=` แล้วเขียนชื่อซ้ำเอง (ปกเคยซ้อนสองชั้น)

## เลือกระนาบตัดจากโมเดล (อย่าเดา)
หาตำแหน่งจาก `model.json` ก่อน เช่น
- รูปตัดพื้น PS: ระนาบต้องตั้งฉากกับแนวแผ่น และผ่านคาน — หาคานแนว y ที่ครอบ y ของระนาบ (KK01: y 6.00 ผ่านคานแนว 3 ที่ x 4.9–5.1)
- รูปตัดผนัง: หาช่องว่างในกล่องผนังแนวนอกที่ z 1.5 เพื่อตัดผ่านหน้าต่าง (KK01: W3 แนว G x 2.0–3.0 ธรณี +0.98 หัว +2.92) — x 7.00 ตกช่องประตู เห็นแต่ธรณี
- รูปตัดฐาน/ตอม่อ/เสา: ผ่านจุดกริด (C3) จะเห็นคานคอดินตามแนวด้วย — ใช้ได้
- รายละเอียดทุกอันต้องมี `plane=` ไม่งั้นไม่มีลายตัด; กรอง parts ด้วย `in_box()` รอบรูปตัดเพื่อความเร็ว

## ชนิดรูปทรง
- กล่อง (`b`) → part ของ dwg_lib (มีลายตัดตามวัสดุ `mc`: conc, lean, sand, brick, plaster, steel, rebar, paint, tile, wood, glass, equip)
- สามเหลี่ยม (`v`,`f`: โครงหลังคา กระเบื้องหลังคา ถัง โคม) → `draw_meshes` ใช้ hull ของจุดในระนาบมอง (ไม่มีรูปตัด) ใช้ได้กับผังและรูปด้าน
- เส้นโค้ง (`p`) → เหล็กเสริม ST01–06 แปลงเป็นกล่องบางตามช่วงตรง (เห็นในรูปตัด) / ท่อร้อยสาย ท่อประปา → `draw_lines` สีตามระบบ
- class ใหม่ต้องเพิ่มทั้ง `D.TINT` และ `D.CUTFILL` (เคยพัง KeyError 'ce_CL1')
- ผังโครงหลังคา: วาดตามลำดับชั้น (อะเส → อกไก่ → ตะเข้ → จันทัน → ระแนงบนสุด) ไม่ใช่ตามความลึก และระบายสีตามชนิด + legend เหมือนแบบ Revit
- ผังหลังคา: ลูกศรทางน้ำไหล = ทิศแนวนอนของ normal ระนาบกระเบื้อง + "30°"
- ผังฝ้า: แผ่นฝ้าก่อน แล้ว overlay ผนังตัดที่ +3.00 (view ที่ 2 บนพื้นที่เดียวกัน) + ป้าย CL1/CL2/CL3 + ระดับ
