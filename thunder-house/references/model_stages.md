# ปั้นโมเดลก่อสร้างทีละขั้น (ST00–ST20)

โมเดลก่อสร้างคือบ้านที่ปั้นตามลำดับงานจริง ชิ้นละ 1 วัสดุ ขนาดจริง เพื่อถอดปริมาณได้ตรงจากรูปทรง
โค้ดตัวอย่างครบทั้งหลังอยู่ใน `scripts/model/` (บ้าน KK01: คสล. 1 ชั้น 13.0 × 12.2 ม., ผ่านการตรวจทุกขั้น)

## โครงสร้างโค้ด
| ไฟล์ | หน้าที่ |
|---|---|
| `kk01_load.py` | โหลดทุกโมดูลตามลำดับเข้า namespace เดียว · ห้ามชื่อฟังก์ชัน/ค่าคงที่ (ตัวพิมพ์ใหญ่) ซ้ำข้ามไฟล์ — กันการเขียนทับเงียบ ๆ |
| `th_base.py` · `th_steel.py` | `mat()` วัสดุ · หน้าตัดเหล็กรีดเย็น (C มีปีก, เหล็กกล่อง, 2C) + กล่องเอียงตรวจชน (OBB) |
| `kk01_struct.py` | กริด ฐานราก ตอม่อ + เครื่องมือกลาง: `_boxes_data` (เก็บรูปทรงเป็นกล่อง), `qto` (ถอดปริมาณ), `_each` (ตรวจทุกชิ้นแล้วรายงานข้อผิดพลาดทั้งหมดในครั้งเดียว), `selfcheck()` |
| `kk01_beams/floor/cols/walls/roof/cover/ceiling/paint/tiles/elec/conduit/units/sanitary/extras.py` | ST03 … ST18 แต่ละขั้น: `build_*()` + `*_report()` + `_check_*()` |
| `kk01_furniture.py` | ST20 เฟอร์นิเจอร์ (ไม่นับปริมาณ) — ใช้ได้ทั้งโมเดลก่อสร้างและโมเดลขาย |
| `build_kk01.py` | สร้างทั้งหลังจาก Blender ว่าง ทีละขั้น ตรวจหลังทุกขั้น แล้วพิมพ์ report |
| `test_stNN.py` | ทดสอบแบบ mutation: แก้ค่าให้ผิดทีละข้อ แล้วต้องเห็นตัวตรวจจับได้ด้วย tag ที่ถูก — ผลต้อง `problems: 0` |

รัน: `blender -b --factory-startup --python-exit-code 1 -P build_kk01.py` (ตั้ง `KK01_OUT` เพื่อบันทึกไปไฟล์ทดลอง)

## ลำดับขั้น
| ขั้น | งาน | สิ่งที่ตรวจ (ตัวอย่าง) |
|---|---|---|
| ST00 | กริดอาคาร | ชื่อ/ระยะกริดตามแบบ |
| ST01 | ฐานราก + ทราย + คอนกรีตหยาบ + เหล็กตะแกรง | ระยะหุ้ม จำนวนเหล็ก หลุมขุดซ้อนกันนับครั้งเดียว |
| ST02 | ตอม่อ + เหล็กยืนขาตีนช้าง + ปลอก | ยอดตอม่อใต้คาน เหล็กยืนถึงระยะทาบ |
| ST03 | คานคอดิน + ข้อต่อคาน–เสา + ทราย/คอนกรีตหยาบใต้คาน | ระยะทาบที่แนวยาวเกิน 10 ม. ไม่ชนกัน |
| ST04 | พื้นสำเร็จ PS + ท็อปปิ้ง + ตะแกรง / พื้นหล่อในที่ | เว้นช่องเสา ขั้นลงห้องน้ำ |
| ST05 | เสา + เหล็กทาบ + เพลทหัวเสา | ยอดเสาใต้อะเส |
| ST06 | ผนังอิฐ + เสาเอ็น/ทับหลัง + ฉาบ | ช่องเปิดตามขนาดวงกบ + ช่องเผื่อ ฉาบหยุดที่ฝ้า |
| ST07 | โครงหลังคาเหล็ก (อะเส อกไก่ ตะเข้ ดั้ง จันทัน ระแนง) | ระยะห่าง ไม่ชนกัน ไม่จมคอนกรีต |
| ST08 | มุงกระเบื้อง + ครอบ + เชิงชาย + เมทัลชีท | พื้นที่ลาด = แปลน / cos มุม |
| ST09–ST11 | ฝ้า · สี · กระเบื้อง + บันได | สีหยุดที่ฝ้า/กระเบื้อง ระดับผิวพื้น |
| ST12 | ไฟฟ้า: อุปกรณ์ + ท่อร้อยสายตามวงจร | ท่อไม่ลอย ไม่ชน รัศมีโค้ง |
| ST14 · ST16 · ST18 | ประตูหน้าต่าง · สุขาภิบาล · รายการย่อย | ท่อลาด ฝังดินพอ ถังไม่ชนบ้าน |
| ST20 | เฟอร์นิเจอร์ทรงก้อน (นำเสนอ) | ไม่ชนบานประตู ทางเดิน ≥ 0.80 ม. · ไม่เข้า selfcheck |

## กติกาที่ได้จากงานจริง
- **อ่านระดับจากแบบให้ชัดก่อนปั้น** แล้วจดเป็นข้อตีความ เช่น “+0.80 = ผิวกระเบื้อง” → โครงสร้างต้องต่ำกว่าผิวตามความหนาวัสดุปู;
  “+4.30 = หลังอะเส” → ยอดเสา/ผนังอยู่ใต้อะเส ไม่ใช่ที่ +4.30
- **ทุกขั้นมี spec ของตัวเอง** (`STxx_*_spec.md`): ค่าที่ใช้ ที่มา (แผ่นแบบ / BOQ / สมมติ) และตารางเทียบ BOQ — ผู้ใช้ให้ใช้ค่า recommend เมื่อแบบไม่ชัด แต่ต้องจดไว้
- **รูปทรงเก็บเป็นกล่อง** เท่าที่ทำได้ (ถอดปริมาณตรง ตรวจชนง่าย) ส่วนเหล็กเส้น/ท่อเป็น curve ที่วัดความยาวได้
- **ตรวจครั้งเดียวเห็นทุกข้อผิด** (`_each`) และ build จาก Blender ว่างทุกครั้งที่แก้ — อย่าแก้ไฟล์ .blend ด้วยมือ
- ขั้นหลังที่เปลี่ยนตัวเลขขั้นก่อน (เช่น ผิวกระเบื้องทำให้โครงสร้างต้องลด) → แก้ต้นทาง แล้ว build ใหม่ทั้งหลัง ไม่ปะท้ายสาย
- งานโครงสร้างทุกชิ้นเป็นแบบร่าง ต้องให้วิศวกรโยธาที่มีใบอนุญาตตรวจและลงนาม

## เริ่มบ้านหลังใหม่
คัดลอก `scripts/model/` ไปที่ `Construction/scripts/` ของโปรเจกต์ แล้วแก้ทีละขั้นจากบนลงล่าง:
กริดและฐานรากใน `kk01_struct.py` → ตารางคาน → แผ่นพื้น → เสา → ตารางผนัง/ช่องเปิด → หลังคา … build และให้ผ่านทีละขั้นก่อนไปขั้นถัดไป
